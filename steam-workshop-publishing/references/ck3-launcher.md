# CK3 专用：Paradox Launcher → Steam 创意工坊

仅适用于 Crusader Kings III（CK3，Steam AppID `1158310`）。不把以下入口、描述文件和文件名推广至其他游戏。

## 证据等级与当前版本

Steam 商店确认 AppID 及 Workshop 功能。CK3 社区 Wiki 公开镜像记载了下列入口及元数据惯例；直接 Wiki 原站本次不可读取，未取得可确认当前启动器版本的官方逐屏操作文档。按钮名称、位置、必填字段、覆盖规则、初发可见性及缩略图要求**必须在实际操作当场核对**。本流程未登录、未运行启动器、未实测上传。来源见 [sources.md](sources.md)。

## 本地准备

- 确定实际 Mod 根目录（包含该 Mod 的 `descriptor.mod` 及游戏内容），区分旁边用于本机注册的 `.mod` 文件。检查 `name`、`version`、`supported_version`、标签及既有 `remote_file_id` 等实际元数据。不要把本地注册文件中的 `path` 或任何本机绝对路径泄露到发布目录。社区资料称 `descriptor.mod` 不需要本地路径字段；以当前支持的上传内容格式为准。
- 更新：从已知条目 URL 或创意工坊管理页确认 item ID，和实际绑定字段（如 `remote_file_id`）、游戏 AppID、名称与拥有/编辑权限交叉核对。有冲突或 ID 未知即阻断。不得清空绑定或随意补写；备份并让用户确认任何必要修正。
- 初发：确认尚无对应条目和残留绑定；发现旧 ID 时先查明归属，不擅自清理。创建后保存平台返回的新 ID，重新核对绑定。
- 社区资料记载 Steam 缩略图在 Mod 根目录使用 `thumbnail.png`。按 PNG 实际编码检查；推荐导出正方形 640×640 作为易读的起点（不是强制尺寸），以小于 1000000 字节作为保守体积预算。源母图保留在发布目录外。长图不自动替换该文件。现场若要求不同，记录并重新确认。

## 在线入口（社区参考、现场复核）

1. 用户本人打开本机 Steam，登录具有对应发布权限的账号，检查在线模式、社区/上传服务可达、拥有适用游戏。通过受支持方式打开 CK3 启动器；不凭账号名称或界面截图断言权限。
2. 在当前启动器查找 Mod 管理/Mod library 及 Upload Mod（名称及位置可能变动）；选择既有本地 Mod，确认目标平台为 Steam Workshop，而非 Paradox Mods。若确实还没有本地 Mod，创建本地骨架属于另一项本地操作，不等于创建 Workshop 条目。
3. 检查界面所识别的发布模式、目标 ID、描述、名称、标签、版本、缩略图等，尤其是更新时自动填入的旧文案和被同时覆盖的字段。不因选中同名 Mod 就认定更新目标正确。
4. 先展示 [通用流程](general-workflow.md) 的确认信息。未得到当前提交动作授权时，停在本地预览/说明，不触发 Upload。若登录、Guard 或协议界面出现，由用户本人处理；核对完成后再按门禁判断。
5. 经授权且满足所有条件后，才可由受支持方式提交，记录回执及准确 ID。社区资料曾描述初发条目为私有；不要把该历史行为当承诺。发布完成也不等于公开，必须回读真实状态。
6. 如需要页面文案、画廊或可见性调整，先按同一 ID 查看旧内容，单独展示计划并取得相应授权；逐张处理画廊，核对实际页面。最终按三层证据验收；测试订阅时区分本地开发版和下载副本，不擅自删除或退订。

### 常见阻断

- Steam 离线、未登录、无网络或社区/上传服务不可达：仅离线准备；恢复条件后重新确认，不强制加速器。
- 找不到 Upload Mod：核对启动器版本、平台及是否具备受支持入口；不自动转 SteamCMD。
- 更新 ID 不明或冲突：不新建、不清空 ID；由用户核对条目管理页和本地绑定。
- 初发回执不明：先按返回 ID 或用户条目列表查找，不直接重复 Upload。
