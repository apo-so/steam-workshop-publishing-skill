# Steam 创意工坊发布与核验

目标：让发布者从真实的 Mod 内容生成可审阅的发布材料，明确目标与权限，避免误新建、误更新和误公开。默认只准备、转换预览图、预览、检查及交接，不执行平台写入。

## 1. 先确定任务边界

- 识别游戏、AppID、发布渠道、初发或更新、Mod 内容根目录、Mod 版本、目标可见性、拟修改字段。未知就标为待核；离线准备无需等齐网络事实。
- 预览、准备、检查、拟稿、生成发布包都不是上传授权。创建条目、上传文件、保存网页编辑、增删画廊、改可见性、依赖或标签等均是独立的外部变更。
- 不索取、读取、传输、填写或记录 Steam 密码、Steam Guard、验证码、会话令牌、Cookie；账号登录、安全验证和法律协议阅读/接受由用户本人操作。遇协议或安全挑战停止外部变更。不要绕过账号、地区、内容或平台限制。
- 此技能没有上传器。仅在用户明确授权当前动作且已展示和确认具体目标、内容与影响后，才可在允许的工具和游戏支持的渠道内协助执行；若没有合适工具，由用户本人操作。当前授权不得推定为后续动作授权，上传并不授权公开。

## 2. 选择渠道，读取必要资料

始终先读 [通用发布流程](references/general-workflow.md)。查规则时读 [来源与证据边界](references/sources.md)，需要现场重新确认的事实不得标为实测。

- CK3（AppID 1158310）且使用 Paradox Launcher：另读 [CK3 专用流程](references/ck3-launcher.md)。其他游戏不套用此流程或文件名。
- 其他游戏：从该游戏官方创作/上传文档确认入口、支持格式和权限。Steam 网页编辑、游戏工具、启动器与 SteamCMD 不能相互替代。SteamCMD 仅在游戏官方明确支持该用途时另读 [SteamCMD 条件流程](references/steamcmd.md)。
- 当前无网、Steam 离线、未登录或上传服务不通：继续本地准备；将在线检查和提交标为阻断，不伪造回执。不把加速器当作必需项。

## 3. 离线准备并展示

1. 从可核查的改动、游戏内截图、测试记录或版本文件提取玩家实际能看到的变化；缺证据的兼容性、DLC/依赖、功能与性能声明不写成事实。
2. 生成一份 `description.bbcode` 作为唯一正文源；用同一源生成离线 HTML 审稿预览，不另写一份发布正文。核对桌面与手机宽度、标签、链接、图片及可读性。长图只作审稿，不能自动进入缩略图或画廊。
3. 按 UTF-8 原始正文计字节：包括 BBCode、URL、空格、实际换行，不含文件开头 UTF-8 BOM。Valve API 描述上限 8000 字节；本技能默认预算 7800 字节，超过预算则修订并重核，不能按汉字数替代。
4. 分开封面母图、待发布主缩略图、按玩家阅读顺序的画廊图。需要转换时用 [离线预览图转换](references/local-tools.md#预览图转换) 另存 PNG/JPEG，不覆盖母图。检查实际编码、尺寸、体积和放大可读性。UGC API 主图与追加/替换图片采用严格低于 1000000 字节的保守预算；网页画廊上限必须在当前入口核查，不外推。
5. 核对发布内容根目录和逐文件清单（相对路径、字节数、SHA-256）；排除密钥、私有资料、绝对路径、本地注册文件、审稿材料及其他非发布内容。只检查，不擅删原文件或修改 ID。
6. 展示实际 BBCode、离线预览、缩略图及画廊顺序、内容清单、版本与证据、预期可见性和新旧字段对照。

可用 [本地检查工具](references/local-tools.md) 重跑字节、保守 BBCode 预览、图片和门禁检查；脚本不联网、不上传，门禁只评估输入声明，并非真实权限或授权证明。无 Python 或 Pillow 时可人工检查并注明未运行工具；不因此绕过门禁。

## 4. 外部变更门禁

提交前重新读取/确认：游戏和 AppID、正确条目 ID（更新必需；初发必须确认确实没有对应条目）、条目名称和账号可写权限、账号具备工坊投稿资格（受限账户不能投稿）、适用游戏使用资格、入口支持、Steam 在线及实际服务连通性（按渠道确认）、版本与内容哈希、改动字段和保留字段、目标可见性、协议状态、当前入口限制。任何必需事实缺失、ID 冲突或上次提交不明，暂停外部变更。不要用标题猜 ID，不清空既有 ID，不把更新改为初发。

先让用户核对最终差异、文件和哈希；再取得针对该动作和目标的明确授权。用户拒绝、只要求预览、授权过期、内容或目标发生变化、意外出现新条目或协议时停止。SteamCMD 独立核查，不要求一定运行 Steam 桌面客户端。

## 5. 分阶段核验与交接

- 提交结果不明、等待邮箱验证或平台审核时先按 ID 回读；保留既有 ID，不因作者可见或订阅者仍用上一版就重复创建。初发尚无 ID 时检查用户自己的条目列表和回执，无法排除已创建就不重试。不得循环创建。
- 分别记录：上传回执、条目页面及实际可见性/文案/媒体、订阅副本实际版本与内容。三者各自为已核实、待核或异常；本地稿、缓存页面、旧订阅不能替代它们。
- 向用户交付准备文件、检查结果、待核事项、未授权/未执行动作。无在线证据只称离线检查或模拟验收，绝不称成功发布。
